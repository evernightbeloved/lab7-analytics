# Лабораторная работа №7 — Google Analytics 4 и Яндекс.Метрика

## Что уже реализовано
- 3 страницы `index.html`, `about.html`, `contacts.html`.
- GA4 с **измерительным ID `G-PP06V3F9L0`** из скриншота настроек потока.
- Один и тот же `analytics.js` подключён в `<head>` **всех трёх страниц**. После согласия он динамически загружает `gtag.js`.
- Автоматическая отправка события `contact_page_view` при посещении `contacts.html` после согласия на аналитику.
- Функция и место для подключения Метрики подготовлены в `analytics.js`, но пока **не включены**: кабинет Метрики временно недоступен и ID счётчика неизвестен.
- Уведомление о согласии: для тестов обязательно выбрать «Разрешить»; иначе данные не собираются.

## Публикация
1. Создайте публичный репозиторий `lab7-analytics`.
2. Загрузите **все 6 файлов** в корень: `index.html`, `about.html`, `contacts.html`, `styles.css`, `analytics.js`, `analytics.svg`.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Сайт: https://evernightbeloved.github.io/lab7-analytics/

## Проверка GA4 — пункт 2.1
1. Откройте опубликованный сайт и нажмите «Разрешить».
2. Пройдите несколько страниц, в том числе контакты.
3. Откройте в GA4 «Отчёты → В реальном времени»; дождитесь появления своего визита. Обработка может занимать несколько минут.
4. Сохраните реальный скрин отчёта. Если данных нет, проверьте блокировку аналитики браузером и DevTools Network (`collect`, `gtag/js`).

## Цель GA4 — пункт 2.3
При открытии `contacts.html` сайт посылает событие `contact_page_view`.
В GA4 после получения события: Администратор → Отображение данных → События (или «Ключевые события» в текущем интерфейсе) → отметьте `contact_page_view` как **ключевое событие**.
Если события пока нет в списке, создайте ключевое событие с таким именем и проверьте в «В реальном времени» или DebugView, что оно поступает.
Этот способ измеряет переход на страницу контактов, как требует методичка.

## Яндекс.Метрика — пункты 2.2 и 2.3
При восстановлении metrika.yandex.ru:
1. Создайте счётчик для сайта https://evernightbeloved.github.io/lab7-analytics/.
2. Откройте `analytics.js` и измените `const YANDEX_METRIKA_ID = 0;` на реальный числовой идентификатор счётчика.
3. Commit changes → подождите публикацию GitHub Pages.
4. Создайте в Метрике цель **Посещение страниц** с условием «URL содержит `contacts.html`».
5. Пройдите сайт после разрешения аналитики, посмотрите отчёты Метрики и сделайте скриншоты.

## Трафик и отчёт — пункты 2.4, 2.5
- Откройте сайт, посетите все три страницы и снова `contacts.html`.
- Повторите тесты в разных браузерах только как фактические учебные визиты, не имитируйте реальных пользователей в отчёте.
- Соберите реальные скриншоты сессий, источников, популярных страниц, ключевых событий.
- Отчёты могут запаздывать. Не указывайте числа, пока они не появились в сервисе.
